# Project Brief



**Project Name:** Financial Sales Performance Dashboard

**Problem:**

The company operates multiple stores and sells products across various categories.

Management currently lacks a centralized view of sales performance.



Management cannot easily answer:

* Are sales increasing or decreasing?
* Which products generate the most revenue?
* Which regions perform best?
* Which customers contribute most revenue?
* Which categories are underperforming?



**Objective:**

Build an interactive Financial Sales Performance Dashboard that enables management to monitor revenue performance and make data-driven decisions.



| Stakeholder      | Needs                       |

| ---------------- | --------------------------- |

| CEO              | Overall company performance |

| Sales Manager    | Sales trends                |

| Regional Manager | Regional performance        |

| Finance Team     | Revenue analysis            |

| Product Team     | Product performance         |





**Revenue Performance**

Questions:

* What is total revenue?
* How has revenue changed over time?
* What is monthly revenue growth? 



**Product Performance**

Questions:

* Which products generate highest sales?
* Which products generate lowest sales?
* Which categories contribute most revenue?



**Customer Performance**

Questions:

* Who are the top customers?
* What percentage of revenue comes from top customers?



**Geographic Performance**

Questions:

* Which cities generate highest revenue?
* Which states underperform?



**Sales Trends**

Questions:

* Which months perform best?
* &#x20;Are there seasonal patterns?



**Tools** 

* Excel
* SQL
* Power BI



**Primary KPIs**

* Revenue
* Orders
* Unique Customers
* Average Order Value
* Monthly Growth



**Dataset:** 

[Indian Store Data (Kaggle)](https://www.kaggle.com/datasets/abuhumzakhan/store-data?resource=download)
