# Financial Sales Performance Dashboard

## Project Overview

This project analyzes retail sales performance across products, customers, regions, and outlet types using Excel, SQL, and Power BI. The objective was to identify key business drivers, evaluate profitability, and provide actionable recommendations through an interactive dashboard.

## Tools Used

* Excel
* SQL
* Power BI

## Project Workflow

1. Business Understanding & Project Planning
2. Data Cleaning & Preparation using excel
3. Exploratory Data Analysis using SQL
4. Data Modeling in Power BI
5. Dashboard Development
6. Business Insights & Recommendations

## Key Insights

* Total Revenue: ₹250.84 Cr
* Total Profit: ₹37.55 Cr
* Highest Revenue Year: 2023
* Top Category: Seasonal Fruits & Vegetables
* Most Profitable Category: Household Items
* Best Performing Region: North
* Best Performing State: Maharashtra

## Recommendations

* Focus marketing efforts on high-revenue categories.
* Increase availability of high-profit products.
* Improve customer retention initiatives.
* Expand successful regional strategies.
* Monitor discount effectiveness regularly.
